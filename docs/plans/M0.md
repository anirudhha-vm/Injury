# M0 plan — repository scaffold and tooling

## Goal
A reproducible, lint-clean, tested skeleton that enforces the integrity and privacy rules from
day one, so later milestones only add science.

## Files
- Tooling: `pyproject.toml` (uv, hatchling, ruff, mypy strict, pytest+cov), `uv.lock`, `Makefile`,
  `.pre-commit-config.yaml`, `.github/workflows/ci.yml`, `.gitignore`, `.env.example`.
- Guidance: `CLAUDE.md`, `README.md`, `docs/PROJECT_BRIEF.md`, `docs/FILE_MAP.md`,
  `docs/CHANGELOG_REASONING.md`.
- Package skeleton `src/youthtwin/` with one sub-package per layer in brief §6.
- Real code (small, fully tested):
  - `utils/config.py` — config loader.
  - `growth/verification.py` — human-verification gate for transcribed coefficients.
  - `utils/results_guard.py` + `scripts/check_no_hardcoded_results.py` — no untagged numbers in `paper/`.
- `configs/` skeleton — all 16 YAML files from brief §6.1, populated with values the brief fixes.
- `paper/preregistration.md`, `paper/tripod_ai_checklist.md` templates.
- `docs/protocol/` SOP drafts; `docs/ethics/` DRAFT templates (human/legal review required).

## Tests
- `test_verification_gate.py` — raise on real data, warn on synthetic, pass when verified.
- `gates/test_mirwald_girls_verified.py` — `human_gate` marker, fails by design (`make gate`).
- `test_configs.py` — every config loads; BlazePose indices; equation families separate;
  no "expected result" keys in the ablation grid; integrity switches.
- `test_results_guard.py` — untagged numbers flagged; tags, code, references ignored; repo `paper/` clean.
- `test_repo_hygiene.py` — no video/.env tracked; sensitive paths git-ignored; hooks present.

## Acceptance criteria
- `make test lint` green; coverage ≥ 85%.
- CI workflow defined (runs on first push to GitHub).
- Pre-commit hook blocks `*.mp4|*.mov` (and other video), `.env`, and Supabase secret keys.
- `make gate` fails with a clear Mirwald-girls message.

## Out of scope (deliberately)
Maturity equations themselves (M1), any heavy dependency (PyMC, torch, MediaPipe), paper outlines (M9).
