# M1 plan — maturity equations, synthetic cohort, data schema

## Goal
Correct, tested maturity-offset equations; a seeded synthetic cohort generator with known ground
truth (growth, movement traits, exposure, injuries); and the data schema with ingestion and QC.
Everything downstream (M2–M8) is developed against this cohort.

## Files
- `src/youthtwin/growth/maturity_equations.py` — Moore 2015 (boys, girls, boys-stature), Mirwald
  2002 (boys, girls); coefficients from `configs/growth/equations.yaml`; input plausibility checks.
- `src/youthtwin/growth/khamis_roche.py` — raises `NotImplementedError` until a human supplies
  the coefficient table.
- `src/youthtwin/utils/seeding.py`, `utils/provenance.py` — RNG streams; run metadata
  (seed, config hash, git commit, `synthetic` flag).
- `src/youthtwin/sim/growth_sim.py` — Preece–Baines model 1 curves, exact true APHV, sitting
  height / leg length partition, mass, measurement error, sparse visits.
- `src/youthtwin/sim/movement_sim.py` — minimal screening summary features with a per-athlete
  trait and a maturity shift (the injury process needs a load proxy).
- `src/youthtwin/sim/injury_sim.py` — weekly exposure and cause-specific injury hazards from a
  known process; time-loss removes weeks from the risk set.
- `src/youthtwin/sim/cohort.py` — assembles tables, tags `synthetic=True`, writes parquet.
- `src/youthtwin/io/schema.py`, `data/schema/schema.sql`, `docs/data_dictionary.md` — nine tables.
- `src/youthtwin/io/ingest.py`, `io/qc.py`, `io/deid.py` — validation, anthropometric QC (TEM,
  duplicate disagreement, implausible change), pseudonymisation.
- `scripts/make_synthetic_cohort.py` + `make sim`.
- `configs/sim/cohort.yaml` — all generator parameters (assumptions flagged).

## Tests (written with the code, reference values computed by hand)
- `test_maturity_equations.py` — hand-computed reference values for all five equations;
  APHV = age − MO; vectorisation; implausible inputs raise; Mirwald girls gated.
- `test_khamis_roche.py` — raises `NotImplementedError`.
- `test_growth_sim.py` — monotone height; true APHV equals the velocity peak; velocity positive;
  sitting ratio within plausibility range; cohort APHV distribution matches config.
- `test_injury_sim.py` — no events while out of the risk set; effect directions present in the
  generated hazards; outcome groups valid.
- `test_cohort.py` — same seed ⇒ identical tables; different seed ⇒ different; 300 athletes ×
  12 months; every table flagged synthetic; truth tables kept separate from observable tables.
- `test_schema.py` — DDL executes; DDL columns match the pydantic models; synthetic cohort
  validates against the schema.
- `test_qc.py`, `test_deid.py`, `test_ingest.py`.

## Acceptance criteria
- Reference-value tests pass; Mirwald-girls gate in place and exercised.
- `make sim` generates 300 athletes × 12 months reproducibly from the seed.
- `make test lint` green; coverage ≥ 85%.

## Not in M1
Bayesian growth twin (M2); skeleton-sequence simulation (M6, if needed); sample-size script
(needs an incidence estimate).
