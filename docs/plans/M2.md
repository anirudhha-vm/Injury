# M2 plan — Bayesian growth twin (contribution C1)

## Goal
A hierarchical SITAR-style model that turns sparse stature measurements into a per-athlete
posterior for age at PHV and growth velocity, with honest uncertainty; and a labelled simulation
study that scores it against the true APHV of the synthetic cohort and against the Moore-2015
point estimate.

## Model
`stature_ij = alpha_i + h((age_ij - beta_i) * exp(gamma_i)) + noise`

- `h`: shared natural (restricted) cubic spline in the truncated-power form, written with
  tensor operations so it can be evaluated at parameter-dependent inputs. Linear beyond the
  boundary knots. Knots are fixed positions on the transformed age axis (config).
- `alpha_i` size, `beta_i` timing, `gamma_i` intensity: hierarchical, non-centred.
- Prior on `beta_i`: Normal(Moore-2015 APHV of athlete i, `sd_years`).
- One model per sex (sex-specific population parameters).
- `beta_i` is **not** reported as APHV. APHV is computed per posterior draw as the age at which
  that athlete's fitted curve has maximum velocity: `beta_i + z_peak * exp(-gamma_i)`, where
  `z_peak` is the location of the spline's velocity peak in that draw. This keeps the definition
  of APHV identical to the one used for the truth.
- Inference: NUTS; ADVI available as a fast fallback. Posterior saved as ArviZ InferenceData.
- Incremental update: refit on the extended data, initialised from the previous posterior means.

## Files
- `src/youthtwin/growth/splines.py` — natural cubic spline basis and its derivative (NumPy and
  PyTensor from one implementation).
- `src/youthtwin/growth/sitar_bayes.py` — data preparation, model, fit, update, save/load.
- `src/youthtwin/growth/growth_state.py` — posterior + date → `GrowthState` (APHV, maturity
  offset, height velocity, % of peak velocity; mean, SD, draws) and a 3-month forecast.
- `scripts/fit_growth.py` — fit a cohort directory, write posteriors.
- `scripts/sim_study_growth.py` — simulation study: coverage, MAE vs Moore, figures watermarked
  SYNTHETIC, results table with provenance.
- `configs/growth/sitar.yaml` — knots, priors, sampler settings, acceptance range.

## Tests
- `test_splines.py` — linear outside boundary knots; continuous first and second derivative at
  knots; analytic derivative matches finite differences; NumPy and PyTensor versions agree;
  matches an independent reference construction.
- `test_growth_state.py` — on a hand-built posterior with known curve: APHV equals the velocity
  peak; velocity positive; forecast height ≥ current; SDs reflect draw spread.
- `test_sitar_bayes.py` — data preparation (duplicate means, Moore prior centres, per-sex split);
  model builds; a small slow-marked fit recovers the truth better than the prior.
- Acceptance numbers come from `scripts/sim_study_growth.py`, not from unit tests.

## Acceptance criteria (brief §6.2)
- Empirical coverage of 90% posterior intervals for APHV within 85–95% on the synthetic cohort.
- APHV MAE lower than the Moore point estimate on the same athletes.
- Incremental update works.
- Figures watermarked SYNTHETIC.

If a criterion is not met it is reported as not met, with the numbers.

## Scope decisions
- Stature only in M2. Sitting height, leg length and mass models (needed for leg-length and mass
  velocity in the growth state) follow the same code path and are added once the stature model
  is validated.
- Known caveat to state in the write-up: Moore's equation was not derived on this synthetic
  population, so "beats Moore on synthetic data" is weak evidence. The real test is H1 on
  athletes who pass PHV during follow-up.
