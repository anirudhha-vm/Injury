# M3 plan — pose and kinematics pipeline

## Goal
Video → keypoints → filtered trajectories → task events → joint angles → tidy task features,
with explicit conventions, units, and quality control, and with every v2 kinematics defect
covered by a regression test.

## Files
- `src/youthtwin/pose/skeletons.py` — landmark indices and canonical joint names (single source
  of truth): BlazePose-33, Halpe-26 (RTMPose with feet).
- `src/youthtwin/pose/keypoints.py` — `KeypointSequence` (pixels, y down, per-frame timestamps
  in ms, confidence), parquet + JSON persistence. Never stores or references raw video.
- `src/youthtwin/pose/estimators/{base,mediapipe,rtmpose}.py` — `PoseEstimator` interface;
  MediaPipe Tasks `PoseLandmarker` (not the deprecated `mp.solutions.pose`); RTMPose via `rtmlib`.
  Heavy dependencies are an optional extra, imported lazily.
- `src/youthtwin/pose/filtering.py` — confidence-gated gap filling (linear up to N frames, else
  NaN), zero-lag 4th-order Butterworth, derivative on true timestamps, residual analysis.
- `src/youthtwin/pose/sync.py` — two-phone offset by cross-correlation of a shared signal.
- `src/youthtwin/pose/events.py` — DVJ, single-leg squat, hop events with confidence; manual
  override.
- `src/youthtwin/pose/kinematics.py` — knee flexion, hip flexion, ankle dorsiflexion (sagittal);
  knee FPPA, pelvic drop, trunk lateral lean, knee-to-ankle separation ratio (frontal).
- `src/youthtwin/pose/task_features.py` — per-trial features at events, ranges of motion, peak
  angular velocities, 101-point curves; per-session means and event-based asymmetry; QC with a
  logged exclusion table.
- `src/youthtwin/sim/skeleton_sim.py` — stylised synthetic skeleton sequences with known angles
  and event frames (test bed; also needed in M6).
- `scripts/run_pose.py` — local video directory → keypoints + features (keypoints only persist).
- `configs/pose/events.yaml`; extend `estimator.yaml`.

## Tests (the brief's named regression tests)
- `test_landmark_indices.py` — BlazePose lower limb 23–32; code and config agree.
- `test_angle_conventions.py` — knee flexion 0° at full extension and equal to 180 − included
  angle; hip, ankle conventions; reference triangles worked by hand.
- `test_fppa_synthetic_skeleton.py` — FPPA recovers a known frontal-plane angle, positive for
  valgus on both limbs, independent of sagittal flexion; pelvic drop and trunk lean signs.
- `test_filtering.py` — gap rules; −3 dB at the cut-off; zero phase lag; velocities in deg/s
  from true (uneven) timestamps; NaN gaps are not bridged.
- `test_events.py` — events recovered on synthetic sequences within a frame tolerance; missing
  events reported, not invented; manual overrides.
- `test_event_asymmetry.py` — asymmetry only from event values; unilateral tasks compare limbs
  across trials, never within a frame.
- `test_task_features.py`, `test_keypoints_io.py`, `test_sync.py`, `test_pose_pipeline.py`
  (end-to-end on synthetic keypoints).

## Acceptance criteria
- All tests above pass; `make test lint` green.
- End-to-end run on a short local clip: **cannot be met yet** — needs `TODO(human)`: 2–3
  consented or self-recorded adult test clips and the MediaPipe model file. Until then the
  pipeline is verified from keypoints onward on synthetic sequences, and the estimator wrappers
  are unverified against real video.

## Scope decisions
- 2D per-camera angles (sagittal from the side camera, frontal from the front camera). Two-camera
  triangulation and OpenCap stay optional and out of M3.
- Tuck-jump features are not implemented (no agreed event definition yet); the task stays in the
  config and is reported as unsupported rather than silently skipped.
