# M5 plan — athlete-week table, exposure, load proxies, baseline and hazard models

## Goal
Turn the data tables into a leakage-safe athlete-week dataset and fit the tabular
cause-specific hazard models, verified on the synthetic cohort where the true effects are known.

## Files
- `src/youthtwin/features/person_period.py` — one row per athlete-week at risk:
  predictors known at the start of the week (growth state, latest screening features carried
  forward with "weeks since screen", exposure history, prior injury, sex, sport) and, per
  outcome group, whether an injury of that type starts in the following 4 weeks. Weeks during
  time-loss are outside the risk set.
- `src/youthtwin/features/exposure.py` — weekly hours, sessions, exponentially weighted load
  (configurable half-life). ACWR is not computed as a primary feature.
- `src/youthtwin/features/mech_load.py` — load **proxies** (C4): knee-extensor moment and
  patellar-tendon proxy; Achilles proxy. No invented anatomical constants: proxies are defined
  up to an unknown constant factor, which standardisation removes.
- `src/youthtwin/eval/splits.py` — athlete-grouped stratified K-fold, nested inner folds,
  temporal hold-out, leave-one-academy-out.
- `src/youthtwin/models/baselines.py` — age only; maturity offset + growth velocity; screening
  features only (all logistic).
- `src/youthtwin/models/risk/hazard_logit.py` — elastic-net discrete-time logistic hazard with
  natural-spline terms for continuous growth variables; preprocessing fitted inside the model
  on training rows only.
- `src/youthtwin/models/risk/hazard_xgb.py` — gradient-boosted hazard, optional monotone
  constraints.
- `configs/features/person_period.yaml`, updates to `configs/models/*.yaml`.

## Tests (brief regression tests)
- `test_no_label_leakage.py` — no predictor is derived from the outcome window or from truth
  tables; label-defining columns cannot be model inputs; a deliberately leaked column is caught.
- `test_scaler_fit_scope.py` — scalers and spline knots are fitted on training rows only:
  changing held-out rows cannot change the fitted preprocessing.
- `test_splits.py` — zero athlete overlap across folds, inner folds, temporal hold-out.
- `test_person_period.py` — risk set, 4-week outcome window, carry-forward, censoring at the
  end of follow-up.
- `test_exposure.py`, `test_mech_load.py` — reference values by hand.
- `test_hazard_models.py` — models fit and predict probabilities; on the synthetic cohort the
  penalised hazard recovers the simulated effect **directions**.

## Acceptance criteria (brief §7)
- Leakage tests pass.
- On synthetic data the hazard model recovers the simulated effect directions.
- Split overlap = 0.
- `make test lint` green.

## Scope decisions
- For M5 the growth predictors on synthetic data come from the growth twin's posterior means
  when a saved posterior is supplied, otherwise from Moore-2015 estimates and finite-difference
  velocities from the measurements. Truth tables are never read.
- Evaluation metrics beyond what the acceptance check needs belong to M7.
