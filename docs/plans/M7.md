# M7 plan — evaluation suite, explanation, figures, provenance

## Goal
Everything needed to report a prediction model per TRIPOD+AI: discrimination, calibration,
clinical usefulness, uncertainty of each estimate, robustness across subgroups, explanations —
and one command that regenerates every figure and table with a provenance record.

## Files
- `src/youthtwin/eval/metrics.py` (extend) — AUC at the 4-week horizon (the cumulative/dynamic
  time-dependent AUC for a fixed horizon on the athlete-week risk set), PR-AUC, Brier score,
  sensitivity and specificity at pre-specified thresholds.
- `src/youthtwin/eval/calibration.py` — calibration intercept (calibration-in-the-large) and
  slope; ICI (mean absolute difference between predicted risk and a smoothed observed risk) and
  ECE (binned); calibration curve data.
- `src/youthtwin/eval/dca.py` — decision-curve analysis: net benefit over threshold
  probabilities with treat-all and treat-none references (Vickers & Elkin 2006).
- `src/youthtwin/eval/bootstrap.py` — athlete-level cluster bootstrap: confidence intervals for
  any metric and for differences between two models on the same athletes.
- `src/youthtwin/eval/subgroups.py` — metrics by sex, maturity stratum, sport, age band.
- `src/youthtwin/explain/shap_utils.py` — SHAP for the tabular hazard models, always on the
  fitted estimator, mapped back to input names.
- `src/youthtwin/explain/integrated_gradients.py` — attributions over channels and time for the
  encoder.
- `src/youthtwin/explain/counterfactual.py` — "what if exposure were 20% lower": change in
  predicted risk, labelled as model sensitivity, not a causal effect.
- `src/youthtwin/eval/predictions.py` — out-of-fold predictions for a set of models in one tidy
  table (the input to every metric, figure and table).
- `scripts/evaluate.py`, `scripts/make_figures.py`; `make paper-figs`.
- `configs/eval/metrics.yaml` (thresholds, bootstrap size, age bands).

## Tests
- Hand-worked values for every metric; agreement with scikit-learn where it implements the same
  quantity; a perfectly calibrated simulation gives intercept 0, slope 1, ICI near 0; known
  miscalibrations are detected with the right sign.
- Net benefit by hand; treat-all and treat-none identities; a useless model never beats both.
- Cluster bootstrap: resamples athletes, not rows; interval covers a known value at about the
  nominal rate; wider than a naive row bootstrap when rows are correlated within athlete.
- `test_shap_runs.py` (v2 regression): SHAP runs on the fitted booster; additivity holds.
- `test_api_contract.py` (v2 regression): one typed interface from table to prediction for
  every model kind.
- Figures carry provenance and the SYNTHETIC watermark; `check_no_hardcoded_results.py` passes.

## Acceptance criteria (brief §7)
- Every figure and table regenerated from one command.
- `check_no_hardcoded_results.py` passes.
- `make test lint` green.

## Scope notes
- With fixed-horizon binary outcomes on athlete-weeks, rows are not independent (overlapping
  4-week windows, repeated athletes). Point estimates are computed on rows; all uncertainty
  comes from resampling athletes.
- Risk thresholds for sensitivity/specificity are still a `TODO(human)` pre-registration item;
  the code takes them from config and reports none if none are set.
