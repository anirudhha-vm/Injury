Standard warm-up, then tasks in fixed order. Demonstrate once; no technique coaching.

| Task | Trials | Notes |
|---|---|---|
| Drop vertical jump (DVJ) | 3 | Drop from box, land on both feet, immediately jump maximally |
| Single-leg squat | 3 per leg | Controlled descent and return; hands on hips |
| Tuck jump | 10 s continuous | Knees to chest, land in the same spot |
| Single-leg hop for distance | 3 per leg | Stick the landing; record distance |

## Trial validity
A trial is repeated if the athlete loses balance, steps off incorrectly, or leaves the frame.
Record every attempt; invalid attempts are marked, not deleted.

## Stopping rule
Stop a task if the athlete reports pain; record it and inform the physiotherapist. Screening is
not a diagnostic assessment.
